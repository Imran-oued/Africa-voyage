## 🛠️ Stack Technique

* **Build Tool & Dev Server** : [Vite 5](https://vitejs.dev/)
* **Structure & Sémantique** : HTML5 multi-pages (`index.html`, `offres.html`, `guide.html`)
* **Fichier de Données Centralisé** : [`data/content.json`](data/content.json)
* **Styles & Design System** : Vanilla CSS moderne (*Spiritual Luxury*, Glassmorphism, animations)
* **Moteur Client** : JavaScript ES Modules (`app.js` avec convertisseur FCFA/EUR/USD, simulateur, modales)

```bash

# 2. Lancer le serveur de développement

# 3. Compiler pour la production
npm run build
```
